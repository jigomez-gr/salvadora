Principio de Seguridad Arquitectónica: La API Key privada de VAPI y los IDs de asistente residen exclusivamente en el servidor del CRM Salvadora. La landing web realiza la petición al CRM mediante el endpoint habilitado, y el CRM se encarga de contactar con VAPI, registrar el lead en base de datos interna y abrir la llamada hacia el móvil del cliente.

1 Flujo de Ejecución Paso a Paso

Paso 1
Usuario Web
Introduce su teléfono en el modal de la landing y pulsa "Llamar Ahora".
Paso 2
Landing → CRM
La web hace POST a /api/widget/vapi/call del CRM.
Paso 3
CRM → Vapi.ai
El CRM registra el contacto y ordena a VAPI iniciar la llamada saliente.
Paso 4
Vapi → Teléfono
Suena el móvil del cliente inmediatamente con la voz del asistente.

2 Endpoint del CRM Salvadora

POST https://crm-salvadoraconesa.jigretera.com/api/widget/vapi/call

En desarrollo local: http://localhost:3001/api/widget/vapi/call

Campo Tipo Presencia Descripción y Formato
phoneNumber string Obligatorio Teléfono de destino en formato internacional E.164 (Ej: +34600112233).
name string Opcional Nombre del cliente para saludo personalizado en la llamada (Ej: "María García").
agentKey string Opcional Identificador del agente CRM. Por defecto: "booking".
sessionId string Opcional ID de sesión del chat para vincular la llamada al hilo conversacional en la bandeja CRM.
inquiry string Opcional Motivo o contexto de la consulta (Ej: "Reserva clase Hatha Yoga y Baño de Gong").

4 Código de la Ruta API Proxy (Server-side)

Archivo src/app/api/vapi/call/route.ts en el proyecto de la landing:

import { NextResponse } from "next/server";

export async function POST(req: Request) {
  try {
    const { phoneNumber, name, agentKey = "booking", sessionId, inquiry } = await req.json();
    if (!phoneNumber) {
      return NextResponse.json({ success: false, error: "El número de teléfono es obligatorio." }, { status: 400 });
    }

    const CRM_API_URL = process.env.NEXT_PUBLIC_CRM_API_URL || "https://crm-salvadoraconesa.jigretera.com";

    const crmRes = await fetch(`${CRM_API_URL}/api/widget/vapi/call`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        phoneNumber,
        name: name || "Visitante Web",
        agentKey,
        sessionId: sessionId || "web_guest",
        inquiry,
      }),
    });

    const crmData = await crmRes.json();
    return NextResponse.json(crmData, { status: crmRes.status });
  } catch (error: any) {
    return NextResponse.json({ success: false, error: error.message || "Error interno al procesar llamada." }, { status: 500 });
  }
}

5 Manejador en el Modal / Componente de la Landing

Función de disparo con autoformato E.164 (añade prefijo +34 a teléfonos españoles automáticamente):

const handleVapiCall = async (phoneInput: string, clientName?: string, inquiryText?: string) => {
  let phone = phoneInput.trim();
  if (!phone) return;

  // Auto-formateo a prefijo internacional si el visitante omitió el '+'
  if (/^[6789]\d{8}$/.test(phone)) {
    phone = `+34${phone}`;
  } else if (!phone.startsWith("+")) {
    phone = `+${phone}`;
  }

  const res = await fetch("/api/vapi/call", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      phoneNumber: phone,
      name: clientName?.trim() || undefined,
      inquiry: inquiryText || "Consulta general desde la web",
      sessionId: "web_sess_" + Math.random().toString(36).substring(2, 9),
    }),
  });

  const data = await res.json();
  if (!res.ok || !data.success) {
    throw new Error(data.error || "No se pudo iniciar la llamada.");
  }
  return data; // { success: true, message: "Llamada iniciada con éxito.", callId: "..." }
};

6 Webhook de Cierre de Llamada (Automático)

El CRM tiene habilitado el webhook en POST /api/widget/vapi/webhook. Cuando el usuario cuelga la llamada, VAPI envía de forma automática el evento end-of-call-report con la grabación en MP3, la transcripción completa y el resumen de acuerdos. El equipo de la landing no tiene que programar nada para este webhook, el CRM lo procesa y guarda internamente.

8 Checklist de Verificación para el Equipo de Landing

Estado Elemento Comprobación esperada
✔ Prefijo E.164 El número enviado al endpoint siempre empieza con + (ej. +34600112233). Si el usuario escribe 600112233, el frontend lo transforma antes de enviar.
✔ Nombre del Usuario Campo opcional en el formulario. Si se envía, la voz de la IA saluda al cliente por su nombre: "¡Hola María! Te llamo desde Salvadora Conesa...".
✔ Feedback Visual Mostrar estado de carga ("Conectando llamada...") mientras se ejecuta la petición, y estado de éxito con cuenta atrás de cierre ("¡Llamada en curso! Tu teléfono sonará en segundos").
✔ Fallback Telefónico Si la petición falla o no hay conexión, mostrar enlace directo para llamada manual: tel:+34695172625 (695 172 625).
✔ Trazabilidad CRM El lead queda creado en el CRM con la etiqueta lead_landing_vapi y la llamada registrada en el historial del CRM.
