1. Objetivo del Requerimiento

En la landing web del Centro Salvadora Conesa se ha habilitado un canal directo denominado "Pedir por Teléfono (VAPI)". Cuando un visitante introduce su número de teléfono solicitando una llamada inmediata, la web realiza una petición a los servidores del CRM para que éste invoque a la API de Vapi.ai y conecte al cliente con el asistente de voz de Salvadora.

Principio de Seguridad Arquitectónica: La API Key privada de VAPI nunca debe residir en el navegador del cliente. Es el servidor del CRM Salvadora quien custodia las credenciales de VAPI, selecciona el asistente correspondiente y registra el lead en la base de datos interna.

2. Flujo de Ejecución Paso a Paso

Paso 1
Usuario Web
El usuario introduce su teléfono en el widget y pulsa "Lanzar Llamada".
Paso 2
Frontend → CRM
La web hace POST al endpoint /api/widget/vapi/call del CRM.
Paso 3
CRM → Vapi.ai
El CRM registra el contacto y ordena a Vapi iniciar la llamada saliente.
Paso 4
Vapi → Teléfono
El teléfono del usuario suena inmediatamente con la voz del asistente.

3. Endpoint a Habilitar en el CRM Salvadora

POST https://crm-salvadoraconesa.jigretera.com/api/widget/vapi/call

3.1. Parámetros del Request Body (JSON)

Campo Tipo Presencia Descripción y Formato
phoneNumber string Obligatorio Teléfono de destino en formato internacional E.164 (Ej: +34600112233).
name string Opcional Nombre del cliente o interlocutor (Ej: "María García").
agentKey string Opcional Identificador de agente. Por defecto: "booking".
sessionId string Opcional ID de la sesión del chat para vincular la llamada al hilo conversacional.
inquiry string Opcional Motivo o contexto de la consulta (Ej: "Reserva taller de respiración").

3.2. Ejemplo de Petición JSON (Payload del Frontend)

{
  "phoneNumber": "+34600112233",
  "name": "María García",
  "agentKey": "booking",
  "sessionId": "web_sess_94812a",
  "inquiry": "Información sobre precios de clases de yoga y baños de gong"
}

4. Lógica Interna que debe Ejecutar el CRM

4.1. Variables de Entorno en el Servidor del CRM

El equipo de backend del CRM debe configurar en su .env:

# Credenciales de Vapi para el Centro Salvadora
VAPI_PRIVATE_API_KEY="vapi_live_xxxxxxxxxxxxxxxxxxxxxxxx"
VAPI_PHONE_NUMBER_ID="0c74a9b1-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
VAPI_ASSISTANT_ID="9f1b5e32-xxxx-xxxx-xxxx-xxxxxxxxxxxx"

4.2. Llamada saliente hacia la API oficial de Vapi

El backend del CRM realiza un POST a https://api.vapi.ai/call/phone con la siguiente estructura:

// Petición saliente desde el CRM hacia VAPI:
POST https://api.vapi.ai/call/phone
Headers:
  Authorization: Bearer {process.env.VAPI_PRIVATE_API_KEY}
  Content-Type: application/json

Body:
{
  "phoneNumberId": process.env.VAPI_PHONE_NUMBER_ID,
  "assistantId": process.env.VAPI_ASSISTANT_ID,
  "customer": {
    "number": phoneNumber,
    "name": name || "Visitante Web"
  },
  "assistantOverrides": {
    "variableValues": {
      "nombre_cliente": name || "amigo/a",
      "consulta_origen": inquiry || "Información general",
      "sessionId": sessionId
    }
  }
}

5. Formato de Respuestas HTTP del CRM

Respuesta Exitosa (200 OK)

{
  "success": true,
  "message": "Llamada iniciada con éxito.",
  "callId": "c62a84d2-f542-...",
  "phoneNumber": "+34600112233"
}

Error de Validación (400 Bad Request)

{
  "success": false,
  "error": "El número de teléfono es obligatorio y debe tener formato E.164 (+34...)"
}

6. Código de Referencia para el CRM (Node.js / TypeScript)

export async function handleVapiOutboundCall(req, res) {
  try {
    const { phoneNumber, name, inquiry, sessionId } = req.body;

    if (!phoneNumber || !phoneNumber.startsWith('+')) {
      return res.status(400).json({ 
        success: false, 
        error: "Número inválido. Debe incluir prefijo internacional E.164 (Ej: +34...)" 
      });
    }

    // Disparar llamada en Vapi
    const vapiRes = await fetch("https://api.vapi.ai/call/phone", {
      method: "POST",
      headers: {
        "Authorization": `Bearer ${process.env.VAPI_PRIVATE_API_KEY}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        phoneNumberId: process.env.VAPI_PHONE_NUMBER_ID,
        assistantId: process.env.VAPI_ASSISTANT_ID,
        customer: { number: phoneNumber, name: name || "Visitante Web" },
        assistantOverrides: {
          variableValues: { nombre_cliente: name, motivo: inquiry, sessionId }
        }
      })
    });

    const data = await vapiRes.json();
    if (!vapiRes.ok) {
      return res.status(502).json({ success: false, error: data.message || "Error al contactar con VAPI" });
    }

    // Registrar Lead / Llamada en la BD del CRM
    // await db.calls.create({ phone: phoneNumber, name, callId: data.id, status: 'initiated' });

    return res.status(200).json({
      success: true,
      message: "Llamada lanzada con éxito mediante VAPI.",
      callId: data.id
    });
  } catch (error) {
    return res.status(500).json({ success: false, error: error.message || "Error interno del servidor" });
  }
}

7. Funcionalidad Opcional: Webhook de Cierre de Llamada

Para que el CRM almacene automáticamente la transcripción, la grabación MP3 y el resumen del acuerdo (ej. reserva confirmada), se recomienda registrar en Vapi el webhook:

POST https://crm-salvadoraconesa.jigretera.com/api/widget/vapi/webhook

Vapi enviará automáticamente el evento end-of-call-report con transcript, summary y recordingUrl al finalizar cada llamada.
